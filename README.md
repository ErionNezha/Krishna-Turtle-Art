# 🦚 Krishna-Turtle-Art

Art i Krishna-s i vizatuar me Python turtle — këtu si simulim i animuar në canvas: fytyra, fyelli e penda e palloit vizatohen vijë pas vije me ar në sfond të zi.

## 🚀 Si ta hapësh

Hap `index.html`, kliko **Live Demo** — vizatimi animohet automatikisht. Origjinalin Python (`original/krishna.py`) e ekzekuton me `python3 krishna.py`.

## 📁 Struktura

```
Krishna-Turtle-Art/
├── index.html
├── demo/  (simulimi canvas + krishna.py)
├── original/krishna.py  (origjinali i paprekur)
├── README.md
```
